# LMNT Coaching Knowledge Base

## PAR-Q readiness gate
Before programming, confirm PAR-Q is cleared. If chest pain, dizziness, or joint pain is reported, pause programming and refer to a physician. Document referral in the assessment record.

## First session talking points
- Welcome the member and confirm their primary goal (strength, fat loss, return-to-training, sport).
- Explain how sessions will run: warm-up, main lifts, accessory work, cooldown.
- Set expectation for feedback after every session — pain, RPE, and readiness scores are mandatory.
- Ask about sleep, stress, and nutrition baseline without prescribing a diet unless qualified.

## Pain and escalation
If a member reports pain above 3/10 during a movement, stop the exercise, regress the pattern, and note it in session feedback. Create a follow-up task for the centre manager if pain persists across two sessions.

## Progression principles
- Beginners: 2–3 full-body sessions per week, focus on squat, hinge, push, pull patterns.
- Intermediates: add weekly progression on primary lifts (2.5–5 kg) when RPE ≤ 8 and form is stable.
- Deload every 4–6 weeks or when readiness scores drop below 6 for two consecutive sessions.

## Session structure template
1. Warm-up 8–10 min (mobility + activation)
2. Primary lift 4 sets
3. Secondary lift 3 sets
4. Accessory 2–3 exercises, 2–3 sets each
5. Cooldown 5 min

## Communication style
Be direct, encouraging, and specific. Use the member's name. Reference their last session data when available. Avoid medical claims.

## Coach Mirror scenarios (self-assessment prompts)
Use these frames when preparing for common coaching moments:

### Lead enquiry
Qualify goal, timeline, training history, and budget sensitivity. Offer a consult — do not quote packages without understanding needs.

### First session
PAR-Q gate, movement screen, set session rhythm, agree on feedback habit (pain/RPE/readiness).

### Floor coaching
Short cues, breathing, tempo. If pain > 3/10, stop and regress. Note flags for next session.

### Progress check
When scale stalls, review adherence, sleep, protein, and performance metrics — not just weight.

### Renewal / price objection
Recap outcomes (strength, consistency, confidence). Anchor value before discussing price. Offer a clear next step.

### Sales consult (CLOSE OS)
Discovery → align programme to goal → handle objections (time, money, spouse) → trial or close with specific date.
